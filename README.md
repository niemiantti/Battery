# Two Josephson-coupled charge islands as a Hamiltonian time crystal

Simulation code and data for the paper *Charge-locked ergotropy and Josephson-split frequencies of a two-island time crystal* (A. J. Niemi).

The model is a pair of charge islands coupled by a Josephson junction,

    H = E_C (N_1^2 + N_2^2) - E_J cos(phi_1 - phi_2),        Q = N_1 + N_2 conserved,

on the truncated charge ladder |m_1|, |m_2| <= M. The code computes the charge-locked ergotropy
E_min(P, q) - E_p(P) by Lagrange duality, the T = 0 sector structure (parity splitting delta_J), and integrates
the symmetry-covariant quantum Landau-Lifshitz-Gilbert (qLLG) flow at fixed mean charge or under a prescribed
slow leak of the total charge. Units: hbar = E_C = 1, time in hbar/E_C, Gilbert parameter kappa = 1/2.

## Layout

```
src/two_islands.py   model, covariant qLLG kernel, sub-commands hull | duality | relax | leak
src/staircase.py     Fig. 1 data: dual staircases, T=0 hull, delta_J(E_J), thermal-segment slopes
src/diagnostics.py   recomputes the diagnostics quoted in the paper from data/
src/make_figures.py  Fig. 1 and Fig. 2 from data/
data/                saved runs used in the paper (.npz) and their logs
figures/             figures generated by make_figures.py
reproduce.sh         the exact commands that produced data/
```

## Requirements

Python >= 3.10 with numpy, scipy and matplotlib (`pip install -r requirements.txt`).

## Quick start

```
cd src
python make_figures.py        # Fig. 1 and Fig. 2 from the saved data (seconds)
python diagnostics.py         # cutoff check, drifts, energy balances, plateau means (seconds)
python staircase.py           # regenerates data/pair_staircase.npz (a few minutes)
python two_islands.py hull    # T=0 sector energies and delta_J for several E_J (seconds)
```

## Reproducing the dynamics

All runs use E_J = E_C/2 and kappa = 1/2. Wall times are for one core.

| command | content | cutoff | time |
|---|---|---|---|
| `python two_islands.py relax 2 --beta 2` | locking from two charges on island 1 (Fig. 2a,b) | M = 5 | ~10 min |
| `python two_islands.py relax 2.5 --beta 2` | moving minimum at fractional charge (Fig. 2b) | M = 5 | ~10 min |
| `python two_islands.py leak 0.00025 --beta 4` | slow leak, parity-split plateaus (Fig. 2c,d) | M = 4 | ~30 min |
| `python two_islands.py leak 0.00025 --beta 2` | same at higher temperature (Fig. 2c,d) | M = 4 | ~30 min |
| `python two_islands.py leak 0.0005 --beta 2`, `... 0.002 --beta 2` | faster leaks (dissipated fractions) | M = 4 | 15 / 4 min |
| `python two_islands.py relax 2 --beta 1` | trapping near thermal saddles (supplement) | M = 5 | ~6 min |

`reproduce.sh` lists these commands in order. Each run prints its summary (energy balance, plateau means,
drifts) and writes `data/pair_relax_q<q0>_J<EJ>_b<beta>.npz` or `data/pair_leak_<gamma>_J<EJ>_b<beta>.npz`;
the logs of the runs behind the paper are in `data/logs/`.

## Data format

`pair_relax_*.npz`: array `R` (complex) with columns
`t, <N1>, <N2>, E, mu, <e^{i theta}>, <T1>, <T2>, ||Y||, ||[K,rho]||, spectral drift`, plus `EG` (Gibbs energy)
and `Emin` (constrained minimum at the initial charge).

`pair_leak_*.npz`: array `R` (real) with columns
`t, <Q>, <N1>, E, mu, D, |<e^{i theta}>|, |<T1>|`, where `D = kappa Tr(Y^2)` is the internal dissipation rate,
plus `EG`.

`pair_staircase.npz`: `q`, the curves `W_T0_J{EJ}` (pure orbit) and `W_b{beta}_J{EJ}` (Gibbs orbits) of the
locked ergotropy, and `EJs`, `dJ` for the parity splitting.

## Preparation of the initial states

Integer charge on island 1 is prepared exactly by the boost `T_1^n rho_G T_1^{-n}` of the Gibbs state. Such a
state is block diagonal in the total charge and has zero charge mobility, so the covariant flow cannot change its
mean charge. Fractional charge is injected by running the prescribed-rate flow while island 1 is weakly coupled
to an external phase reference, `H -> H - E_x cos(phi_1)` with `E_x = 0.3 E_C`, until the target charge is
reached; the coupling is then removed and the state is relaxed at fixed charge (`prepare()` in `two_islands.py`).
